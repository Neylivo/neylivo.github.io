Windows

Скачать для Windows

Требования: Windows 10 или 11, 64 бита. Ставится для текущего пользователя, права администратора не нужны.

Обновления: Приложение обновляется само: новая версия скачивается в фоне и ставится, когда закрываешь окно.

Windows может предупредить о неизвестном приложении. Установщик не подписан сертификатом — сертификат стоит денег, которых у проекта нет. В окне SmartScreen нажми «Подробнее», затем «Выполнить в любом случае». Отключать антивирус или SmartScreen ради установки не нужно — ни ради этого приложения, ни ради какого-либо другого.

Android

Версия 1.557.0 15.9 MB 12 августа 2026 г.

Скачать APK

Требования: Android 7.0 и новее. Ставится вручную из файла APK — в Google Play приложения нет.

Обновления: Приложение само проверяет новые версии и предлагает их поставить.

Android попросит разрешение на установку приложений из этого источника. Такой запрос появляется для любого приложения не из магазина: разреши его браузеру или файловому менеджеру, которым открываешь файл. Отключать Play Защиту или другую системную защиту не нужно.

Веб

Без установки

Открыть NeyLivo

Требования: Любой современный браузер: Chrome, Edge, Firefox, Safari. Ставить ничего не надо.

На телефоне веб-версию можно добавить на главный экран — дальше она ведёт себя как установленное приложение.

Что выбрать

  • Приложение для Windows — если NeyLivo всегда открыт: оно живёт в трее, продолжает уведомлять при закрытом окне, записывает клипы и умеет показывать накладку звонка поверх игры.
  • Приложение для Android — для телефона. Та же учётная запись, те же серверы и переписка.
  • Веб-версия — чтобы посмотреть NeyLivo за полминуты или на компьютере, куда нельзя ничего ставить.

Как проверить, что скачал

Каждый выпуск собирается GitHub Actions из открытого исходного кода, а файлы прикладываются к выпуску. Кнопки выше ведут прямо на эти файлы. Сверить скачанное можно на странице выпусков:

Все выпуски и их файлы →  ·  Что изменилось в этой версии →

Установщик Windows не подписан сертификатом, а APK подписан собственным ключом проекта, а не ключом магазина. Значит, происхождение файла подтверждается тем, откуда он взят, а не удостоверяющим центром.
